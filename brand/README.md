# Brand source files

Master files from the designer (2026-10-01). Not served by the site.

- `Cornerstone_BrandStyleGuide_261001` — logo usage, palette, fonts
- `Cornerstone_LogoSet_261001` — vertical logo, horizontal logo, icon, wordmark

Palette: Slate `#2C3A47`, Sienna `#B95827`. Fonts: Machine Regular (modified, logo only), Barlow (tagline and site text).

The web assets in `public/brand/` (SVGs, favicons, social share image) were exported from the LogoSet PDF.
The `*-reversed.svg` variants swap Slate for white for use on dark backgrounds; they are not in the designer's set.
